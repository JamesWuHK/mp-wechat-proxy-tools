# 微信公众号全流程运营

## 流程总览

| 阶段 | 做什么 | 依赖 |
|------|--------|------|
| ① 账号管理 | 注册、绑定、订阅、状态查询 | `mp-proxy` CLI |
| ② 选题规划 | 理解生意 → 找热点×生意结合点 → 出角度 | AI 搜索 + 写作 |
| ③ 内容写作 | 围绕核心观点写 → 审稿 → 本地预览 | AI 写作 |

| ⑥ 运营管理 | 配额监控、发布检查、续费 | `mp-proxy` CLI |

## 首次加载：自动安装与初始化

**写作先行，发布后配。** 不要因未绑定公众号阻止用户写文章。

详见 `references/setup-guide.md`，分两条路径：

| 路径 | 触发词 | 自动做什么 | 需要用户配合 |
|------|-------|-----------|------------|
| 🖊 写作模式 | 「写公众号文章」 | 装 bun + baoyu skills + 问品牌偏好 | 回答品牌问题 |
| 📡 发布模式 | 「发布到公众号」 | 上面全部 + 装 mp-proxy + 绑定公众号 | 提供 AppID/AppSecret |

1. 首次加载时，按 `references/setup-guide.md` **自动检查并安装依赖**（bun、skills、mp-proxy），缺失就装，不询问

## 阶段 ① 账号管理

### 1.1 IP 白名单（用户必须操作一次）

> ⚠️ 先加白名单再注册，不然 API 不通。
> 
> 登录 mp.weixin.qq.com → 设置与开发 → 基本配置 → IP白名单 → 添加 **`49.233.1.9`**

### 1.2 注册与绑定

```bash
mp-proxy signup "<机构名>" <英文简称> <AppID> <AppSecret> "<公众号名称>"
mp-proxy onboarding
mp-proxy accounts
```

> **定价**：写作不限量。发布：免费试用 5 篇 → 首月 ¥9.90 → 之后 ¥29.90/月（含 2 个公众号）。用 `mp-proxy pricing` 查最新价格。

## 阶段 ② 选题规划

**核心原则：不找热点，找热点 × 生意的结合点。**

### 2.1 确认三件事（必须先问）

动笔前搞清楚客户的核心信息。EXTEND.md 有则读，无则推断并确认：

| 问题 | 目的 |
|------|------|
| **做什么生意？** | 公众号给什么服务/产品引流？ |
| **人设是什么？** | 在读者心中什么角色？ |
| **目标读者？** | 文章写给谁看？ |

### 2.2 找热点 × 生意结合点

1. 搜索行业/社会热点（带数据来源）
2. 每个热点问：「这事对客户的**生意**意味着什么？」
3. 人设过滤：「客户用人设讲这个，能说出别人说不出的东西吗？」

### 2.3 出 3 个选题角度

三个角度差异化：**认知**（看法）、**行动**（怎么做）、**反直觉**（你以为对的其实不对）。

每个含：热点简述 → 与生意交叉点 → 一句话核心角度 → 2-3 点大纲。

**用户选一个后，追问核心观点**：「对这件事，你最想说什么？一句话。」

## 阶段 ③ 内容写作

### 3.1 围绕核心观点搭建

```
热点钩子 → 客户独到视角（那一句话） → 为什么别人没想到？
         → 论证（数据/案例/逻辑） → 读者能做什么
         → 署名 + 下篇预告
```

### 3.2 写作原则

- ✅ 一篇只讲一个核心观点——客户那"一句话"是锚
- ✅ 用客户的语气和人设写
- ✅ 行动建议具体可执行
- ❌ 不贩卖焦虑、不复制新闻、正文不卖产品

### 3.3 审稿 + 本地预览

写完先给用户审，逐段改到满意。然后本地预览：

```bash
bun <baoyu-post-to-wechat>/scripts/wechat-api.ts article.md --dry-run
# → 在浏览器打开生成的 HTML 看公众号效果
```

## 阶段 ⑤ 排版发布

两种方式。**优先推荐 API 方式**（更稳定、不受设备限制）。

### 5.0 方式选择

| 方式 | 稳定性 | 设备限制 | 推荐场景 |
|------|--------|---------|---------|
| **API 方式**（推荐） | ⭐⭐⭐ 高 | 无限制，换电脑换手机都能触发 | 日常发布 |
| Browser 方式 | ⭐⭐ 中 | 需要本地 Chrome + 登录态 | 备用/无 API 凭证 |

**为什么推荐 API 方式？**
- 通过 `mp-proxy` 付费服务代理，服务器 IP 已加入微信白名单，不存在 `40164 IP 不在白名单`
- 不依赖本地 Chrome，换了电脑 / 用手机打开 WorkBuddy 照样能发布
- 支持定时自动群发（需公众号已认证）
- 不会被浏览器超时、登录态过期打断

### 5.1 API 方式发布命令

```bash
bun .../wechat-api.ts article.md \
  --theme modern --author "作者" --cover cover.png \
  --product-link "https://store.weixin.qq.com/..." \
  --product-text "课程名 · ¥199 →"
```

### 5.2 关键参数

| 参数 | 说明 |
|------|------|
| `--theme` | default/grace/simple/modern |
| `--color` | blue/green/red 等 |
| `--cover` | 封面图路径 |
| `--product-link` | 文末自动嵌入的产品链接 |
| `--product-text` | 链接显示文字 |
| `--dry-run` | 仅渲染不发布（用于预览） |

### 5.3 自动行为

- **产品链接注入**：`--product-link` 设置的链接自动加在文末
- **旧草稿清理**：发布后自动删除同名旧版本草稿
- **封面自动压缩**：>10MB 自动 resize

### 5.4 定时自动发布

> ⚠️ `freepublish/submit` 需**已认证**公众号。未认证只能后台手动群发。

## 注意事项

1. **凭据安全**：不显示 AppSecret、MP_AGENT_KEY
2. **写作先行**：未绑公众号也能写作，发布时再绑
3. **先选题后写作**：选题必须用户确认
4. **品牌一致**：一切以用户 EXTEND.md 为准
5. **不预设行业**：不假定读者、风格、领域
